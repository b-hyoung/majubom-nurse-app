> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 알람 화면 안에 서버 ToF 3D 자세 뷰를 작은 칸으로 함께 보여준다.

**Architecture:** 서버 `tof_3d.html`에 `?embed=1` 모드(HUD 숨김)를 추가하고, 앱은 `react-native-webview`로 `{base}/tof/3d?embed=1`을 띄운다. 알람·폴링 로직은 그대로.

**Tech Stack:** Expo 57, React Native 0.86, react-native-webview, jest-expo. 서버는 정적 HTML.

### Task 2: 3D 칸 컴포넌트 (앱)

**Files:**
- Create: `src/Tof3D.tsx`
- Modify: `package.json` (의존성)

- [ ] **Step 1:** `npx expo install react-native-webview`
- [ ] **Step 2:** `src/Tof3D.tsx`

```tsx
import React from 'react';
import { StyleSheet, Text, View } from 'react-native';
import { WebView } from 'react-native-webview';
import { tof3dUrl } from './api';

// 서버 ToF 3D 뷰(embed 모드)를 알람 화면 안 작은 칸으로. 조작 없이 보기만.
export function Tof3D({ base, offline }: { base: string; offline: boolean }) {
  return (
    <View style={s.box}>
      <View style={StyleSheet.absoluteFill} pointerEvents="none">
        <WebView source={{ uri: tof3dUrl(base) }} style={s.web} scrollEnabled={false} originWhitelist={['*']} />
      </View>
      <View style={s.tag}><Text style={s.tagText}>ToF 3D</Text></View>
      {offline && (
        <View style={s.off}><Text style={s.offText}>3D 연결 끊김</Text></View>
      )}
    </View>
  );
}

const s = StyleSheet.create({
  box: { height: 220, marginHorizontal: 16, marginBottom: 8, borderRadius: 16, overflow: 'hidden', backgroundColor: '#0E1420' },
  web: { flex: 1, backgroundColor: 'transparent' },
  tag: { position: 'absolute', top: 10, left: 10, paddingHorizontal: 8, paddingVertical: 4, borderRadius: 8, backgroundColor: 'rgba(24,32,40,.75)' },
  tagText: { color: '#FFFFFF', fontSize: 12, fontWeight: '700' },
  off: { ...StyleSheet.absoluteFillObject, backgroundColor: 'rgba(138,148,160,.92)', alignItems: 'center', justifyContent: 'center' },
  offText: { color: '#FFFFFF', fontSize: 15, fontWeight: '700' },
});
```

웹(react-native-web)에는 WebView가 없으므로 `src/Tof3D.web.tsx`에 iframe 버전을 둔다 (스크린샷 확인용, Metro가 `.web.tsx`를 자동 선택):

```tsx
import React from 'react';
import { StyleSheet, Text, View } from 'react-native';
import { tof3dUrl } from './api';

export function Tof3D({ base, offline }: { base: string; offline: boolean }) {
  return (
    <View style={s.box}>
      <View style={StyleSheet.absoluteFill} pointerEvents="none">
        <iframe src={tof3dUrl(base)} style={{ border: 0, width: '100%', height: '100%' }} />
      </View>
      <View style={s.tag}><Text style={s.tagText}>ToF 3D</Text></View>
      {offline && (
        <View style={s.off}><Text style={s.offText}>3D 연결 끊김</Text></View>
      )}
    </View>
  );
}
// s 는 Tof3D.tsx 와 동일
```
